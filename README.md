# 冰冷的她醒来之前 · Embalming Girl

一款供本地体验的 3–6 人身份隐藏卡牌游戏。冷色旧校舍、纸质牌面、秘密调查与终局揭晓；支持基础模式，以及保留草稿约定的进阶变体。

## 运行

需要 Node.js 20.19+。

```sh
npm install
npm run dev
```

打开 **http://localhost:5173**。输入称呼即可创建或加入房间，无需注册。多开独立标签页可模拟多名玩家；也可以由房主添加练习席，独自体验完整对局。练习席使用简单合法行动策略。

所有人准备后由房主开始。使用六位房间号或复制的邀请链接加入；刷新页面可恢复原席位。暂离或断线会暂停对局，返回后继续；房主可结束暂停的对局。主动离开会中止当前局并释放席位，房主离开时自动移交。全员离线的房间保留约 30 分钟。

构建并运行本地成品：

```sh
npm run build
npm start
```

打开 **http://localhost:3001**。服务默认仅监听本机；房间保存在内存中，重启服务会清空。此版本没有账号系统或公网部署配置。

## 玩法

每回合从手牌中选择一张，用于调和、质疑或发动能力。所有人只剩一张牌后揭晓身份，按身份优先级判定胜利。规则与卡牌说明可在页面的「游戏手册」中查看。

基础模式：最后一张手牌在自己的回合结束后锁定；不可质疑自己，质疑总点数最低为零。最高质疑点数并列者均被监禁，只有全员相同时无人被监禁。

进阶变体：允许质疑自己与负质疑分，最后一张手牌可被能力移动；保健委员需要额外弃一张手牌。其余规则不变。

## 结构

- `apps/web`：React 界面与连接恢复。
- `apps/server`：WebSocket 房间服务，访客身份适配独立于规则。
- `packages/core`：独立 TypeScript 规则、行动校验、个人视图与结算。

## 本地卡图

默认使用自制文字牌面。若有自有扫描或获准使用的卡图，可将 WebP 文件放入 `apps/web/public/cards/`，在「偏好设置」启用本地原图。缺失的图片自动回退，目录已排除在 Git 之外；构建后如需移除原图，应删除该目录素材并重新构建。

文件名对应：`president` 学生会长、`nurse` 保健委员、`librarian` 图书委员、`prefect` 风纪委员、`lady` 大小姐、`press` 新闻部、`leader` 班长、`honor` 优等生、`criminal` 犯人、`accomplice` 共犯、`alien` 外星人、`infected` 感染者、`home` 归宅部，例如 `nurse.webp`。
